Dépôt APT de mawena

Un seul dépôt signé pour tous mes paquets Ubuntu : on l'ajoute une fois, puis sudo apt install <paquet> pour n'importe lequel et sudo apt upgrade pour tous.

Installation en une ligne

curl -fsSL https://apt.mawena.cloud/installer.sh | sudo sh -s -- gagarine ccs

Sans nom de paquet, le script ajoute seulement le dépôt. Il installe aussi le paquet mawena-depot, qui garde la clé et la source à jour.

Pas à pas

sudo curl -fsSL -o /usr/share/keyrings/mawena-depot.gpg https://apt.mawena.cloud/mawena-depot.gpg
sudo curl -fsSL -o /etc/apt/sources.list.d/mawena-depot.sources https://apt.mawena.cloud/mawena-depot.sources
sudo apt update
sudo apt install mawena-depot <paquet>
